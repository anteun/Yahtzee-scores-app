# Yahtzee-scores-app
App for keeping score of Yahtzee games including statistics of games played.

.apk file can be installed on Android phones. 

Source code added, including build dependencies for buildozer from Kivy.

This is a hobby project, no commercial interests, feel free to add on or use anything. 

Instructions for using the app:

Follows classis Yahtzee game rules, but without bonus Yahtzee.

First time use sets the players in the database of whom the subsequent scores are stored and statistics of the games between those players are displayed in-app.

One-time extra players can be added but those scores are not stored.
